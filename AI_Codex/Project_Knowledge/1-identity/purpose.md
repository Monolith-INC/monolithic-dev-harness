## Summary

The harness joins idea shaping, backlog work, implementation and review while deterministic checks enforce supported operations. It is a developer-side plugin, not a hosted service.

## Detail

The vision names feature owners, technical leads and developers as consumers. README describes Claude Code, Cursor and Codex support and several tracker choices. Constitution Article 11 explicitly says the harness is not in production. Supporting documents can predate current code; their dates are evidence, not a guarantee of current host qualification.
