# IDEA-001: Explore weekly routines

**Kind:** Optional ideation starter
**State:** Use only when the user asks to explore what Daybook could become

## Prompt

“I am not sure how Daybook could help me plan recurring weekly responsibilities. Help me explore the problem and possible directions before choosing a feature.”

## Guardrails

- Treat ideas as possibilities, not evidence or approved requirements.
- Ask about the user's routines and difficulties before settling on a solution.
- Keep product ideation optional; assigned feature requests should start with technical investigation.
