# DAY-002: Add due dates

**Kind:** Feature request
**Size:** Medium
**State:** Draft; clarify date behavior before planning

## Product-owner request

“I want to give a task a due date and find the tasks that are overdue, so I can focus on what needs attention.”

## Questions to resolve

- Is a due date optional for every task?
- Does “overdue” mean before the user's local calendar day, or a specific time?
- Should completed tasks ever appear in the overdue view?
- Which date format and editing interaction fit the current screen?

## Acceptance checks after decisions

- Users can add, edit, and clear an optional due date.
- The task list can show overdue tasks using the agreed local-date rule.
- Existing tasks without a due date continue to work.
