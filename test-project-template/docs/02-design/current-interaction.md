# Current interaction

## Sign in

The first screen contains email and password fields, a sign-in button, and the demo credentials. A successful sign-in opens the task list. Invalid or missing credentials produce a short message. The sign-in state is held in memory and is not sent to a service.

## Task list

The task screen greets the demo user and shows the number of active tasks. A search field narrows the list by task title. The All, To do, and Done filters select which task states are visible. Each task can be marked complete or active, edited, or deleted after confirmation. Add and edit reject titles that contain only whitespace.

An empty list invites the user to add a task. An empty search or filter result explains that no task matches the current view. Signing out returns to the sign-in screen.

Task data is temporary. Restarting the app restores the three sample tasks.
