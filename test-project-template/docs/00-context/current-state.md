# Current state

Daybook is an early Flutter prototype for a person keeping a short list of everyday tasks. The app
starts with three sample tasks, accepts new task titles, and lets the user mark tasks complete.

Tasks live only in memory. Restarting the app restores the sample list and removes tasks added in
the previous session. The app has no accounts, server, synchronization, or external integrations.

This repository is intentionally small. There is no approved plan for expanding the product yet.
