# Start Feature Development

1. Resolve the Active Feature work item through the configured tracker adapter.
2. List child user stories and confirm acceptance criteria and logical states.
3. Publish an implementation-plan artifact on the feature work item.
4. Create the feature branch using the bootstrap-selected `{key}` template.
5. For each story, create a stacked story branch and open a pull request targeting the feature branch.
6. Link each pull request to its tracker work item through the SCM and tracker adapters.
7. Hand off completed story merges to finish-feature-development.
